First release on PyPI: `uvx looker-sync`.

- Install and run with `uvx looker-sync <command>`; nothing else to set up.
- `looker-sync skill` prints the full usage guide written for agents. `--help` stays short.
- `init` now works from a blank folder: it writes an `.env` template and a `.gitignore`
  entry, then resumes once you have filled in the credentials, and offers the first pull.
- `status` shows how many commits the dev branch is ahead of and behind its remote.
- The `looker-sync` skill moves to `skills/looker-sync/` and ships both in the Claude plugin
  and inside the package.

Looker's API has no commit or push endpoint, so committing stays with git.
