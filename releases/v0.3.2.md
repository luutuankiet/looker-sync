`init` now syncs custom visualization JavaScript, docs and locale strings by default.

- A fresh `init` writes `include` as `**/*.lkml`, `**/*.dashboard.lookml`, `**/*.js`, `**/*.md`
  and `**/*.strings.json`, and `exclude` as `**/node_modules/**`.
- Existing projects are unchanged: the lists live in `.looker-sync/config.json`. Add the new
  patterns there yourself if you want them.
- These files go through `pull`, `push` and `watch` like any synced file, deletes included. Only
  `.lkml` files get the syntax check.
- After a fresh `init`, the first `pull` also brings any `.js`, `.md` and `.strings.json` files
  that are in Looker down to your folder.
- Checked against a sandbox Looker, one try each: the file API took `.js`, `.md` and
  `.strings.json`. It refused `.json`, `.topojson`, `.geojson`, `.css`, `.html` and `.txt`, so
  those stay out.
- Still no runtime dependencies.

Upgrade with `uvx looker-sync@latest`.
